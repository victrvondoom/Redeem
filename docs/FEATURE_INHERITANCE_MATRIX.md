# Feature inheritance matrix — RESOLVE and RECLAIM → REDEEM
Method: both repositories were cloned read-only at their current heads (RESOLVE `2f2d1e9`, RECLAIM `96f321d`) and their **source** inspected (module list, docstrings, routes, services, agents, frontend pages, knowledge data, tests), not just READMEs. Nothing from them was executed (an attempt to run RECLAIM's seed scripts was blocked and replaced by reading their static `DOCUMENTS` literals with `ast`). Both are MIT; attribution in `THIRD_PARTY_NOTICES.md`.

Status legend — **PORTED**: source logic copied (unmodified or lightly adapted). **REBUILT**: same capability re-implemented on REDEEM's engine. **EQUIVALENT**: REDEEM already had its own implementation (earlier sprints). **PARTIAL**: some of it. **NOT INHERITED**: not built (reason given). **BLOCKED**: needs an external resource. "Evidence" names the automated tests (`apps/api/tests`, `apps/web/tests`) that exercise it; none of this is live-provider verified.
